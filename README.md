# Slaugth Intendants — BattleScribe HH v1 repository

This is the standalone public BattleScribe repository for the fanmade Slaugth Intendant Dominion army list, packaged in the same four-file layout as the Rangdan Confederacy repository.

## Repository files

- `Slaugth_Intendant_Dominion_HH1.catz` — standalone Slaugth catalogue
- `index.bsi` — BattleScribe Data Index archive containing `index.xml`
- `index.xml` — readable copy of the repository index
- `README.md` — these instructions

Upload all four files to the root of:

`https://github.com/kobychapmans-ship-it/Slaugth-Intendants`

The BattleScribe Data Index URL is:

`https://raw.githubusercontent.com/kobychapmans-ship-it/Slaugth-Intendants/main/index.bsi`

## Install on a phone

1. Open BattleScribe and go to **Manage Data / Data Repositories**.
2. Add the raw `index.bsi` URL above as a new Data Index URL.
3. Refresh data and download **Slaugth Intendants**.
4. Create a roster using **The Horus Heresy (HH v1)** and choose the **Slaugth Dominion Detachment**.

The catalogue targets BattleScribe 2.03 and HH v1 game-system revision 165.

## Included content

The catalogue contains the native Slaugth units, relics, wargear, detachment rules, Herdtalon options, Cythor Fiend material restored from the earlier Slaugth source, Remnant Infected, and the cross-faction rules from **From Diversity, We Flourish** and **Ancient Weaponology** that can be represented safely in BattleScribe.
